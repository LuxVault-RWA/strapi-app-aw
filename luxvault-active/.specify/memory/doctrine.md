# LuxVault Operating Doctrine

- Specs over memory.
- Intent before calldata.
- Policy before signatures.
- Simulate before value moves.
- Public chains are adversarial.
- Agent outputs are proposals, not truth.
- Narrow automation beats broad autonomy.
- Signing is not planning.
- Logs are part of the product.
- Revocation is a feature, not a fallback.
- Token state is not RWA truth.
